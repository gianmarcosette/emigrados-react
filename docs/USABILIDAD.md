# Prueba de usabilidad

Registro de la prueba con una persona externa al proyecto y de los ajustes hechos a partir de ella.

## Datos de la prueba

| | |
|---|---|
| **Fecha** | _completar_ |
| **Persona** | _nombre o iniciales, edad, si emigró o no, desde qué país_ |
| **Dispositivo** | _celular o compu, modelo y navegador_ |
| **Dónde** | _en clase, link de Vercel o compu de desarrollo_ |
| **Duración** | _minutos_ |

## Cómo se hizo

- Se le dio el link sin explicar el juego: solo "esto es un juego para personas que emigraron".
- Se le pidió que pensara en voz alta mientras jugaba.
- Quien observaba no ayudaba: anotaba dónde dudaba, qué tocaba y qué decía.
